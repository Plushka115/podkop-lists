# Общие списки Podkop

Редактируйте **domains.txt**: один домен на строку, без `https://`, путей и `*.`.
Запись `example.com` действует также на все её поддомены.
В **subnets.txt** находятся пользовательские IPv4-подсети, по одной на строку.
Пустые строки и комментарии после `#` поддерживаются.

После сохранения GitHub Actions проверяет файлы и обновляет `domains.json`
и `subnets.json`. При ошибке прежние рабочие JSON-файлы сохраняются.
JSON-файлы вручную редактировать не нужно. Список публичный.

В VPN-секции Podkop на каждом роутере:

- **Remote Domain Lists**: `https://raw.githubusercontent.com/Plushka115/podkop-lists/main/domains.json`
- **Remote Subnet Lists**: `https://raw.githubusercontent.com/Plushka115/podkop-lists/main/subnets.json`
- **List Update Frequency**: каждый час.

Доменные списки загружает и обновляет сам sing-box. Пользовательские локальные
записи при первоначальном переносе заменены этими ссылками. Стандартные списки
сообщества продолжают обновляться из своих источников.

Для немедленного применения можно выполнить `service podkop reload` на роутере.
После удаления подсетей также нужен reload: штатное обновление подсетей Podkop
может сохранять старые элементы в nftables до перезагрузки службы.

Локальная проверка перед публикацией: `python3 build.py`.
